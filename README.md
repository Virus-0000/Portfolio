# Divyanshu Raj — Portfolio

My personal developer portfolio built with **React, Vite, Tailwind CSS, and Framer Motion**.

## 🌐 Live Portfolio

[View Portfolio](https://portfolio-kappa-brown-v0x6efcjn.vercel.app)

## 🛠️ Built With

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- JavaScript
- HTML & CSS

## ✨ Features

- Responsive design
- Premium dark theme
- Smooth animations
- Interactive UI
- Project showcase
- Skills and experience sections
- Resume viewer
- Contact section

## 🚀 Run Locally

    git clone https://github.com/Virus-0000/portfolio.git
    cd portfolio
    npm install
    npm run dev

## 📦 Build

    npm run build
